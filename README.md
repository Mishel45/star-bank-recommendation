# Recommendation Service — Рекомендательный сервис Банка «Стар»

Высокопроизводительный гибридный микросервис на базе Spring Boot для формирования персонализированных маркетинговых предложений клиентам банка на основе анализа их транзакционной активности.

## ✨ Ключевые особенности
* **Гибридный движок:** Параллельная обработка фиксированных предикатов бизнес-логики (Invest 500, Top Saving, Простой кредит) и динамических правил, конфигурируемых в реальном времени через JSON API.
* **Многопоточное кэширование:** Реализация 3-х независимых кэшей Caffeine по паттерну *get-if-absent-compute* для исключения повторных тяжелых дисковых операций к файлу логов.
* **Изоляция данных:** Использование двух изолированных источников данных: PostgreSQL (Read/Write через JPA/Liquibase для правил и статистики) и встроенной H2 Database (Read-Only через JdbcTemplate для транзакций).
* **Многопользовательские интерфейсы:** Доступ к формированию рекомендаций как через стандартный REST API (для интеграции с мобильным банком), так и через интерактивного Telegram-бота (Proof of Concept для аналитиков).

## ⚡ Быстрый старт (Локальный запуск)
1. Поместите эталонный файл базы данных `transaction.mv.db` в корневую директорию проекта.
2. Соберите проект: `.\mvnw clean package`
3. Запустите скомпилированный jar-файл: `java -jar target/recommendation-0.0.1-SNAPSHOT.jar`
