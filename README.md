# 🚀 Recommendation Service — Рекомендательный сервис Банка «Стар»

Высокопроизводительный гибридный микросервис на базе Spring Boot для формирования персонализированных маркетинговых
предложений клиентам банка на основе анализа их транзакционной активности. Система объединяет фиксированные
бизнес-правила, динамический конструктор условий в реальном времени, аналитику срабатываний и интеграцию с
Telegram-ботом.

## 🛠 Стек технологий

* **Язык и фреймворк:** Java 17, Spring Boot 3.3.5
* **Веб-слой:** Spring Web MVC (REST API для клиентов, менеджеров и DevOps-систем)
* **Работа с данными:** Spring JDBC (`JdbcTemplate` для Read-Only логов транзакций), Spring Data JPA (для динамических
  правил и статистики)
* **Базы данных:** H2 Database (файловая БД транзакций `READ_ONLY`), PostgreSQL (основная БД правил и статистики)
* **Миграции и кэширование:** Liquibase (версионирование схемы БД), Caffeine Cache (кэширование запросов по паттерну
  *get-if-absent-compute*)
* **Внешние интеграции:** Telegram Bots API (`StarBankBot`)
* **Сборка и тестирование:** Maven, JUnit 5, MockMvc

## ⚡ Быстрый старт

1. Поместите файл `transaction.mv.db` в корень проекта.
2. Соберите проект: `./mvnw clean package`
3. Запустите приложение: `java -jar target/recommendation-0.0.1-SNAPSHOT.jar`
