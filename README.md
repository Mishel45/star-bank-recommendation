# 🚀 Рекомендательная система для Банка «Стар» (MVP)

Проект представляет собой MVP (минимально жизнеспособный продукт) сервиса персональных рекомендаций банковских продуктов. Сервис анализирует профиль клиента, его транзакции и предлагает релевантные финансовые услуги на основе предопределенных бизнес-правил.

## ⚙️ Функционал первой итерации (Бизнес-правила)

Сервис обрабатывает три пилотных продукта:
1. **Invest 500** (`147f6a0f-3b91-413b-ab99-87f081d60d5a`) — для пользователей дебетовых карт, у которых нет инвест-продуктов, а сумма пополнений сберегательных счетов > 1 000 ₽.
2. **Top Saving** (`59efc529-2fff-41af-baff-90ccd7402925`) — для активных пользователей дебетовых или сберегательных карт (пополнения >= 50 000 ₽), у которых доходы превышают расходы.
3. **Простой кредит** (`ab138afb-f3ba-4a93-b74f-0fcee86d447f`) — для клиентов без открытых кредитов, у которых траты по дебетовой карте превышают 100 000 ₽, но баланс остается положительным (пополнения > трат).

## 📋 Спецификация REST API

### Получить рекомендации для клиента
* **Запрос:** `GET /recommendation/{user_id}`
* **Тип параметра `user_id`:** `UUID` / `String`

* **Пример успешного ответа (200 OK):**
* 
```json
{
  "user_id": "cd515076-5d8a-44be-930e-8d4fcb79f42d",
  "recommendations": [
    {
      "id": "147f6a0f-3b91-413b-ab99-87f081d60d5a",
      "name": "Invest 500",
      "text": "Откройте свой путь к успеху с индивидуальным инвестиционным счетом (ИИС)..."
    }
  ]
}
```

## 🚦 Как запустить проект локально

1. Убедитесь, что у вас установлена **Java 17 SDK**.
2. Поместите файл базы данных `transaction.mv.db` в корень проекта (или укажите корректный путь в `application.properties`).
3. Запустите команду сборки Maven в терминале:
   ```bash
   mvn clean install
   ```
4. Запустите приложение через вашу IDE или команду:
   ```bash
   mvn spring-boot:run
